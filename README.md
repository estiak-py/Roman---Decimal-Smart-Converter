# Roman---Decimal-Smart-Converter
 Number Converter # Roman ↔ Decimal Smart Converter

A Python-based terminal application that converts numbers between **Decimal** and **Roman Numerals** with a clean menu-driven interface.

## Features

- Convert **Decimal → Roman Numeral**
- Convert **Roman Numeral → Decimal**
- Input validation
- Error handling
- Interactive menu system
- Continuous execution loop until user exits
- Professional modular code structure

## How It Works

### Decimal to Roman
The program converts decimal numbers (1–3999) into Roman numerals.

**Example:**

Input:
```bash
1994
```

Output:
```bash
MCMXCIV
```

---

### Roman to Decimal
The program converts Roman numerals into decimal numbers.

**Example:**

Input:
```bash
MCMXCIV
```

Output:
```bash
1994
```
